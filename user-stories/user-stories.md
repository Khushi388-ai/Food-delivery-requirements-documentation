# User Stories

| ID | Story | Req |
|---|---|---|
| US-01 | As a customer, I want to log in with my mobile number and OTP so that I can order securely. | FR-01 |
| US-02 | As a customer, I want to search restaurants by cuisine or name so that I can find food I like. | FR-02 |
| US-03 | As a customer, I want to view a restaurant's menu with prices so that I can choose items. | FR-03 |
| US-04 | As a customer, I want to manage my cart and apply a promo code so that I can see the final price. | FR-04, FR-05 |
| US-05 | As a customer, I want to place an order to my address so that the food is delivered to me. | FR-06 |
| US-06 | As a customer, I want to pay by UPI, card or cash so that I can use my preferred method. | FR-07 |
| US-07 | As a restaurant, I want to accept or reject orders so that I only take orders I can prepare. | FR-08 |
| US-08 | As a customer, I want to track my order live so that I know when it will arrive. | FR-09, FR-10 |
| US-09 | As a customer, I want to cancel an order before preparation so that I am not charged for food I no longer want. | FR-11 |
| US-10 | As a customer, I want to rate my order so that others and the restaurant benefit from my feedback. | FR-12 |
